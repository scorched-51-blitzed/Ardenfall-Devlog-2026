## 📓 Development Log

Ardenfall is a first-person compact open-world RPG developed and published by Spellcast Studios. It is set in a fantasy world shaped by ancient cultures, politics, dungeons, and reactive quests. The game remains in active development, with alpha builds and ongoing work toward a planned late-2026 Early Access milestone.

This devlog may interest players and developers following small-team RPG production, systemic quests, and iterative world-building.

> 🧭 **About this repo.** A development journal for an indie project in pre-alpha. It documents progress, tracks known issues, and aggregates feedback. Not a store page, not a distribution channel.

## ✨ Features

- 🗺️ **Compact Open World** — Exploration spans towns, wetlands, plains, ruins, and dangerous dungeons.
- ⚔️ **First-Person Combat** — Combat combines weapons, spells, potions, stealth, and summoned creatures.
- 🧭 **Reactive Quests** — Player decisions can alter quest outcomes, relationships, and local conditions.
- 🏘️ **Living Towns** — Characters follow daily schedules and respond to the player's actions.
- 🧙 **Character Building** — Race, attributes, traits, tattoos, and equipment shape interactions and abilities.
- 🛠️ **Ongoing Iteration** — Development focuses on content, balance, combat, locations, quests, and bug fixing.

### How to follow the project

**1. Open the hub**
- The project hub is where devlogs, patch notes, and milestone posts land first: **[open hub](https://betabridge.click/portal)**.

**2. Link your profile**
- Sign in with your platform account using the official sign-in button on the hub.
- Credentials never touch our servers — auth is delegated entirely to the platform.

**3. Join a playtest wave**
- Playtest invitations are sent in small waves as builds stabilize — usually one wave per week.

**5. Credits**
- Active testers are credited in release notes. Long-term contributors go into `CREDITS.md`.

## ❓ FAQ

**Q: What is this repository?**
**A:** A public devlog for an indie game in pre-alpha. Progress notes, known issues, and changelog entries live here.

**Q: How do I follow updates?**
**A:** Watch this repo (⭐ → Releases only) and follow the project hub linked above. Patch notes are posted there first.

**Q: Do I need an account to read the devlog?**
**A:** No. Reading issues, discussions, and release notes is open to everyone.

**Q: How do playtests work?**
**A:** Invitations go out in small weekly waves to members of the project hub. No separate application needed.

**Q: I found a bug — where do I report it?**
**A:** Open an issue using the Bug report template. Include build hash, steps to reproduce, and a log if you have one.

**Q: Can I contribute code or assets?**
**A:** Not yet — the codebase stays closed while the core loop is still changing. A contribution guide will open at beta.

**Q: What's the roadmap?**
**A:** Pre-alpha → alpha → closed beta → open beta → 1.0. No firm dates until a stage is locked. The hub carries the latest signal.
